# sieve benchmark report

Generated by `benchmarks/run.sh`. See PRD §11.6 and
`IMPLEMENTATION_PROMPT.md` Phase 15 for methodology.

## Methodology

Each line of each corpus is run through `Scanner::default()` with
the same system prompt (`"You are a helpful assistant."`). The
`Decision` returned is bucketed Block / Flag / Allow. Per-call
latency is measured around `scan_input` only (no I/O).

## Published competitor numbers (cited)

- Lakera Guard: 74.6% (arXiv 2505.13028, independent eval, 2025).
- Azure Prompt Shield: 42.98% (same paper).
- ACL LLMSec 2025 Unicode bypass: 100% evasion against Lakera /
  Azure / Meta Prompt Guard / ProtectAI v2.

Cross-test comparisons are difficult — different test sets, different
attacker assumptions, different cost models. We publish our numbers
with the inputs and the harness so anyone can reproduce them.

## How to extend

- `--jbb path/to/jailbreakbench.json` — JailbreakBench corpus.
- `--garak path/to/garak-probes.txt` — garak probe dump.
- `--acl path/to/acl25-bypasses.txt` — ACL'25 cited samples.

Each external corpus is loaded the same way (one input per line,
blanks + lines starting with `#` ignored) and added as an additional
row in this table on rerun.
