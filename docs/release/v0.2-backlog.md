# v0.2 backlog

Things we deliberately do **not** build in v0.1. Captured here so scope-creep instincts have somewhere to go.

If you find yourself wanting to add one of these during v0.1: open an issue, link this file, move on.

## v0.2 features (in PRD §9)

- Tool-call linter — declarative invariants per tool; reject calls violating contract.
- Provenance-aware RAG scanning + auto-spotlighting (`scan_retrieved(text, provenance)`).
- Conversation state tracker — cumulative risk + canary state + topic drift across turns.
- Piggyback LLM context analyzer (`LlmCallable` trait — user supplies any callable).
- napi-rs Node native binding (`@sieve/node`).
- Go binding (cgo + cbindgen).
- Python contrib: LiteLLM, LangChain, LlamaIndex.
- TOML config-file support for ScannerBuilder.

## v0.3 features

- Bundled reference ONNX classifier weights (opt-in feature, separate distribution).
- Semantic commitment checks via optional LLM-as-judge.
- Differential testing (re-run with normalized input, compare divergence).
- Streaming output scanning (chunk-by-chunk canary + commitment).
- CLI tool (`sieve scan file.txt`).
- HTTP sidecar mode.
- Swift / Kotlin bindings via uniffi.

## v0.4+

- PII detection (separate sister crate, not bundled).
- Custom rule DSL.
- Browser extension.

## Carved out of v0.1 ship

- **WASM-from-Node cross-language consistency test.** `wasm-pack build
  --target nodejs` produces a CJS module whose getrandom JS glue panics
  with `unreachable!` on first call when loaded outside a bundler. Browser
  parity is fine (target=web / target=bundler with a real bundler). v0.1's
  consistency CI tests Rust↔Python only. v0.1.1 fix: either switch the
  test to load the bundler-target build via a tiny Vite/Rollup wrapper, or
  Playwright against a headless browser.

## Stretch ideas (not committed to any version)

- Pluggable canary schemes (format-constrained, embedding-stable phrases).
- Per-language commitment extraction beyond English.
- WASM SIMD path for Aho-Corasick on long inputs.
- Streaming-friendly Unicode normalization (currently fully buffered).
- `serde_json` zero-copy verdict serialization for hot paths.
- WIT bindings for component-model WASM.
